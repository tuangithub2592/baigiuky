PANOEE + MC — BẢN ĐÃ SỬA

Cách chạy:
1. Giải nén ZIP này.
2. Trong VS Code chọn File > Open Folder và chọn CHÍNH thư mục Panoee-MC (thư mục có index.html).
3. Mở index.html > chuột phải > Open with Live Server.
4. URL đúng sẽ là http://127.0.0.1:5500/ hoặc http://localhost:5500/
   KHÔNG chạy dạng /out/index.html.
